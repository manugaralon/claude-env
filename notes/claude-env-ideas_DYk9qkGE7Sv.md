## Transcripción

 Te voy a decir un secreto. Claude Code, Ultra Plan, Goal, Agents, Ultra Review. Este es probablemente el máximo código clave nativo de la lista de comandos de la nueva funcionalidad que han añadido recientemente. Aquí es lo que cada uno hace y cómo puedes unirlos juntos. Ultra Plan desplaza un montón de subagentes en el cloud en servers antropóficos para crear un Ultra Plan locado. Si eres inteligente, recrea Ultra Plan localmente y rúelo tú mismo. Once you have your crazy Ultraplan, SlashGoal has Cloud Code loop over that plan until it achieves the actual goal of that Ultraplan. You can literally loop for days on end. Slash Agents allows you to zoom out on that Cloud Code session and actually have it run in the background. So now it's SlashGoal looping on that Ultraplan and you can start a whole new parallel session. Once that session has achieved a goal, you zoom back into that session and do Slash Ultra Review, which is the same thing as Slash Ultraplan except it deploys a bunch of subagents in the cloud to review all of the code that was produced from that SlashGoal looping session. Si eres muy inteligente, harás esto localmente también, para que no tengas que usar tus créditos de ultra-review. Si quieres aprender más sobre los loops de código agente y la orquestación agente, y quieres usar esos comandos locales, todos los que están hostados en mi comunidad de escuela, en el enlace en la bio, me gustaría verlos.
