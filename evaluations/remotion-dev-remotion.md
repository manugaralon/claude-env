# remotion-dev/remotion

Would be a Node/React project dependency, not a skill/MCP — integration needs a skill wrapper or project template.

## Why this verdict
research-only — genuinely net-new (nothing in the stack produces video; infographics = static, pptx = slides). BUT a React-heavy workflow + non-standard commercial license + no recurring use case for a backend-leaning solo dev make immediate integration unjustified. Revisit if a concrete video-output need emerges (animated changelogs, demo reels, data-driven video).
