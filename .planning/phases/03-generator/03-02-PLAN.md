    Create `claude_env/generator/generator.py` with:

    ```python
    from __future__ import annotations

    from pathlib import Path

    from claude_env.generator.content_catalogue import enrich_artifact_context
    from claude_env.generator.sentinel import merge_sentinel_block, wrap_with_sentinel
    from claude_env.models.generation_plan import Artifact, GenerationPlan, OutputLayer
    from claude_env.templates.registry import TemplateRegistry
    ```

    CRITICAL: Do NOT import `has_sentinel`. The layer determines sentinel behavior, not file content inspection.

    Class `Generator`:
    - `__init__(self, registry: TemplateRegistry) -> None`: store `self._registry = registry`
    - `execute(self, plan: GenerationPlan, project_root: Path, global_root: Path) -> list[Path]`:
      1. Initialize `written: list[Path] = []`
      2. For each artifact in `plan.artifacts`:
         a. Call `self._resolve_path(artifact, project_root, global_root)` to get absolute target path
         b. Call `enrich_artifact_context(artifact, plan)` to get full context dict
         c. Call `self._registry.render(artifact.template_id, context)` to get rendered content
         d. **Layer-aware write logic (branch on artifact.layer, NOT on file contents):**
            - If `artifact.layer == OutputLayer.GLOBAL`:
              - If `target.exists()`: read existing with `target.read_text(encoding="utf-8")`, call `final_content = merge_sentinel_block(existing, rendered_content)` — always, regardless of whether existing has sentinel markers
              - If NOT `target.exists()`: `final_content = wrap_with_sentinel(rendered_content)` — so first write is sentinel-wrapped
            - If `artifact.layer == OutputLayer.PROJECT`:
              - `final_content = rendered_content` (overwrite unconditionally, no sentinel)
         e. Call `target.parent.mkdir(parents=True, exist_ok=True)`
         f. Call `target.write_text(final_content, encoding="utf-8")`
         g. Append target to written
      3. Return written

    - `_resolve_path(self, artifact: Artifact, project_root: Path, global_root: Path) -> Path`:
      1. Determine layer_root: `project_root / ".claude"` if `artifact.layer == OutputLayer.PROJECT`, else `global_root`
      2. Compute `target = (layer_root / artifact.target_path).resolve()`
      3. Security check: `if not str(target).startswith(str(layer_root.resolve())):`  raise `ValueError(f"Path traversal detected: {artifact.target_path}")`
      4. Return target

    Docstrings on class and both methods. Use `from __future__ import annotations` at top.
