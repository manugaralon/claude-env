       - `test_has_sentinel_partial`: only BEGIN without END returns False
       - `test_merge_replaces_existing_block`: create file with "user header\n" + wrapped("old") + "user footer\n", merge with "new", assert "user header" and "user footer" preserved, "old" gone, "new" present
       - `test_merge_appends_when_no_block`: merge into "just user content", assert user content preserved and managed block appended
       - `test_merge_idempotent`: merge same content twice, assert result identical
       - `test_merge_preserves_user_edits_outside_block`: simulate user adding content after the managed block, re-merge, assert user addition preserved
